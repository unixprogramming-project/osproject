# 과제 요구사항 점검표

안내문과 최종보고서 서식 기준. 상태: 완료 / 본측정 필요 / 2단계 / 팀 작업

## 수행 조건
| 요구사항 | 상태 | 근거 |
|---|---|---|
| 3가지 IPC 구현 | 완료 (1단계) | `src/transport_*.c` |
| 팀원별 IPC 1개 담당 | 팀 작업 | 담당자를 정하고 코드 리뷰 |
| 모든 버전을 같은 컴퓨터에서 측정 | 본측정 필요 | 측정용 컴퓨터 결정 |
| 측정 환경 기록 | 완료 | `scripts/collect_env.sh`, `env.txt` |
